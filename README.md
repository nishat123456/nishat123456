## Featured Projects

### [TinyML Eval](https://github.com/nishat123456/tinyml-eval)
**Reproducible evaluation framework for edge audio event-detection policies under real hardware constraints.**
- Proposed Adaptive policy: 97.7% event capture rate, 73.5% data reduction across 200K+ clips
- Statistically validated vs 5 baselines (Mann-Whitney U, p < 0.01, Cohen's d = 1.24)
- **Stack:** Python · scikit-learn · librosa · Bootstrap CI

### [LLM Dashboard v2](https://github.com/nishat123456/llm-dashboard-v2)
**Real-time LLM telemetry pipeline with Kafka, Redis, Prometheus, and Grafana.**
- Event-driven ingestion: LLM call → Kafka → PostgreSQL → Redis cache → Grafana dashboard
- Kubernetes deployment with health probes and resource limits
- **Stack:** Python · FastAPI · Kafka · Redis · PostgreSQL · Prometheus · Grafana · Kubernetes

### [IoT Intrusion Detection](https://github.com/nishat123456/iot-intrusion-detection)
**ML pipeline for network intrusion detection on CICIoT2023 — 508K instances, 34 attack types.**
- 5 classifiers including XGBoost, LightGBM, and LSTM; SHAP explainability + adversarial robustness testing
- **Stack:** Python · XGBoost · LightGBM · LSTM · SHAP · scikit-learn

### [Gulf South Health Analysis](https://github.com/nishat123456/gulf-south-health-analysis)
**Mississippi county health vulnerability analysis — CDC PLACES + SVI + HRSA data pipeline.**
- Identified 16 double-burden counties; K-Means clustering across 82 counties x 13 health measures
- **Stack:** Python · PostgreSQL · pandas · scikit-learn · Socrata API
